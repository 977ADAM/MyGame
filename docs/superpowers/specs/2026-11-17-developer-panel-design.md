# Панель разработчика — выдача предметов

Спецификация согласована · 17 ноября 2026

## Назначение и границы этапа

Панель позволяет быстро получать предметы для тестирования, пропуская ручную добычу и изготовление. Первый этап включает выдачу ресурсов, построек и пустых перфокарт. Пробитые карты игрок создаёт обычным способом; готовые программы панель не выдаёт.

## Открытие, закрытие и пауза

- `F1` открывает панель поверх игры. Повторное нажатие закрывает её.
- При открытии закрываются обычный инвентарь и окна взаимодействия.
- Пока панель открыта, приостанавливаются движение персонажа, добыча, строительство, разбор, крафт и работа построек.
- Кнопки панели продолжают работать во время паузы.
- После закрытия игра продолжается с сохранённого состояния, без скачка таймеров за время паузы.
- Клики по панели не выполняют действий в игровом мире.

## Интерфейс

Все предметы видны одновременно в общей сетке 3 × 3. Каждая кнопка содержит название предмета и `+10`.

| | | |
|---|---|---|
| Железная руда | Уголь | Камень |
| Древесина | Железные пластины | Печь |
| Бур | Ролик | Пустая перфокарта |

## Выдача предметов

- Один отдельный клик выдаёт 10 выбранных предметов, одинаково для всех девяти типов.
- Удержание ЛКМ не повторяет выдачу.
- Сначала пополняются существующие стопки, затем занимаются свободные слоты.
- Действуют обычные ограничения вместимости инвентаря и максимального размера стопок из основной спеки игры.
- Если все 10 предметов не помещаются, выдаётся только вместившаяся часть.
- Не вместившиеся предметы не сохраняются в ожидании.
- При нехватке места отображается `INVENTORY FULL`. Подсказка видна поверх открытой панели.
- При полностью заполненном инвентаре без места в подходящих стопках предметы не меняются и отображается та же подсказка.

## Выбранный подход

Рассмотрены общая сетка и вкладки «Ресурсы / Постройки / Карты». Согласована общая сетка: девять предметов помещаются в одном окне и доступны без переключения вкладок.

Количество фиксировано: 10 предметов за клик. Поле ввода количества и отдельные кнопки для разных количеств не входят в этот этап.

Реализация должна следовать правилу репозитория: простой и понятный код без ненужного усложнения. Для выдачи используется существующая логика добавления предметов в инвентарь.

## Проверка через игру

| Сценарий | Ожидаемый результат |
|---|---|
| Нажать `F1`, затем нажать повторно | Панель открывается и закрывается |
| Открыть панель при открытом инвентаре или окне взаимодействия | Предыдущее окно закрывается |
| Нажать по одному разу каждую из девяти кнопок при достаточном месте | Выдаётся по 10 соответствующих предметов |
| Удерживать ЛКМ на кнопке | Выдача выполняется один раз |
| Получить предмет при наличии неполной стопки | Сначала пополняется существующая стопка |
| Получить 10 предметов, когда помещается только часть | Выдаётся вместившаяся часть, видна подсказка `INVENTORY FULL` |
| Получить предмет при полном инвентаре без места в подходящих стопках | Предметы не меняются, видна подсказка `INVENTORY FULL` |
| Открыть панель во время крафта или плавки, подождать и закрыть | Прогресс заморожен во время паузы и продолжается после закрытия без скачка |
| Открыть панель во время работы бура | Работа и прогресс бура приостанавливаются до закрытия |
| Использовать игровое управление и нажимать кнопки панели | Персонаж не движется, добыча, строительство и разбор не выполняются |
